AoT – Building & Economy

How each faction's base grows from deploy to Age 3: which building goes down when, why, and what runs the economy behind it. Nod's tiers reflect the actual AI base-planner rhythm (deterministic, one build order per match). GDI has no base-planner AI yet — its tiers reflect the designed/manual build order from the production palette instead, marked accordingly.

Source: engine/.../AotBasePlannerBotModule.cs (BuildRhythm, Nod) · mods/cnc/rules/aot-ai.yaml · buildorder.html (GDI palette order) · Ages unlock via aot-age1/2/3-upgrade-* on the Construction Yard (5k / 10k / 15k credits).

NOD

AotBasePlannerBotModule@nod — deterministic Rhythm, AI-driven

Concept. On yard-deploy the planner floods a reachable "Pocket" around the Construction Yard once, finds the enemy-facing gate, packs every building into that pocket, and freezes the whole match's build order as one ordered Rhythm list. The builder module then executes it strictly one item at a time — no bulk/grid guessing at runtime. A step whose actor isn't unlocked yet (age gate) simply blocks the rhythm until the age upgrade finishes; steps needing an out-of-reach cell get a temporary wall bridge (sold again once the real building stands).

Why this order. Power comes first (Silo and everything else needs it), the yard gets its own defensive ring immediately after the first two buildings so the base core is never briefly unfenced. Sub Pen is gated on coastal terrain: the planner only queues it if the base's own reachable pocket actually touches a beach or water-cliff cell — an inland base never gets one (overseas naval production is a later Outpost Operations concern, not a base-rhythm step). STEC (the tech pair's second building) is deliberately moved to the very end of Age 0 (user spec) — Radar Dome still comes early with the power cluster.

Gate defence, staged across ages (user spec). The gate cluster — Turret-FlameTurret- Turret in a single row or column, fenced as one ring, exactly like the power cluster — is fully planned NOW (one Placement, found via a local packer search around the chokepoint), but only the middle slot (Flame Turret) is actually queued in Age 0; the 2 flanking Turrets + the fence ring follow in Age 1. Two SAM Sites are unrelated to the choke — scattered through the base via the ordinary Pocket-wide packer, biased toward the yard so they land within the developed base rather than at the Pocket's edge. Helipad is deliberately last in Age 0, built only once the gate defence's core piece is up.

Why this order. Refinery gets top priority (user spec) — but aot-proc-nod's own Buildable.Prerequisites requires afld to already exist, so it literally cannot go before Airfield: that would deadlock the strict rhythm forever (Refinery waits on a prerequisite that Airfield, stuck behind it in the list, never gets a turn to satisfy). Airfield first is the earliest the Refinery can possibly follow; it's placed immediately next, ahead of everything else in the age.

The two Turrets attach directly beside the already-standing Flame Turret — left/right for a horizontal corridor, above/below for a vertical one — and only once all 3 exist does the fence ring go up around the whole cluster. A power-plant quad funds the superweapon track: Temple of Nod (Ion-Cannon-equivalent) and Missile Silo (nuke superweapon) both come online this age — a full age earlier than GDI's Ion Cannon Uplink (Age 3), the classic Nod glass-cannon identity.

The base-planner Rhythm is otherwise upgrade-only at Age 3 (15,000 credits on the Construction Yard) — Toxic Trooper conversion, Battle Tank Tick-Tank upgrade, Stealth Tank cargo module, and the rest of the per-unit upgrade tree, handled by the separate upgrade-tab system, not the base builder. Two structural exceptions: a single Obelisk of Light placed directly behind the gate cluster, i.e. towards the yard — Cardinal(yard − choke) gives the direction back from the chokepoint into the base, so the Obelisk faces out through the defended gate instead of pointing the wrong way — and a small defence block (1 Flame Turret + 2 Turrets + fence, same shape as the main gate) at every OTHER classified approach into the base (IBotBaseApproachProvider), including Beach-type ones that previously got no fixed defence at all (mobile reserve only). Geometry is decided now, at plan time, like everything else — but every secondary block is placed right after the Obelisk step, so the strict rhythm genuinely can't reach them before Age 3 has begun. Each gets its own local flanking axis (ray-cast at that specific cell, not reused from the main choke — a different gate can face a completely different direction).

Known gap: aot-gate-nod (an actual openable Gate piece for the wall system) exists fully in the ruleset but isn't wired into any fence the AI builds yet — every fence ring the planner builds (Yard/Power/Nuk2a/Gate/secondary) is a fully closed loop with no opening for own units. On a wide corridor units can route around a ring; on a narrow one, a fence built right across the only passable width could seal the base's own chokepoint shut. Not yet addressed.

GDI

Manual production-palette order — no AotBasePlannerBotModule@gdi yet
GDI currently has no base-planner AI (confirmed in Operation → Module 1: "GDI currently has no AotBasePlannerBotModule instance"). The tiers below are the designed build order from the production palette (buildorder.html), not an executed AI rhythm — GDI base-building is still an open item.

Concept. GDI's identity is defensive-economic rather than glass-cannon: tougher armor, later but stronger superweapon (Ion Cannon at Age 3 instead of Nod's Age 1 Temple/Missile Silo), and its own War Factory track for heavier vehicles instead of Nod's Airfield-first air rush.
