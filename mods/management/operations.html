AoT – AI Operations Framework

Combat AI built from the "OpenRA AoT AI Operations Framework v2" briefing. Fully replaces the stock SquadManager (2026-07-21). Modules 1–4 implemented and built (0 errors), still untested in-game. Faction-split instances of AotOperationsBotModule (@nod / @gdi) produce their own mission units; AotMapIntelBotModule provides the shared map analysis. A fixed rally point is set on every Barracks/Hand (which otherwise pick a random Exit cell per unit) so fresh infantry converge and hold at one spot near the building instead of scattering across the base while a mission fills up.
